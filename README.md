# TTM Calculator

Веб-калькулятор для оценки доходности ASIC-майнинга. Позволяет выбрать монету, оборудование и параметры электричества, после чего рассчитывает ориентировочную выручку, расходы и чистую прибыль.

## Демо

[Открыть калькулятор](https://marsel-lang.github.io/ttm-calc/)

## Возможности

- Выбор криптовалюты и ASIC-оборудования
- Учёт энергопотребления и стоимости электроэнергии
- Учёт комиссии пула
- Расчёт дохода, расходов и чистой прибыли
- Отображение актуальных рыночных данных из внешних источников
- Интерфейс, адаптированный для мобильных устройств

## Технологии

- HTML
- CSS
- JavaScript
- Внешние API рыночных и сетевых данных
- GitHub Pages

## Назначение

Проект объединяет веб-разработку и практическую задачу расчёта экономики майнинга. Результаты являются оценочными и зависят от актуальности исходных рыночных и сетевых данных.
